> *"Service Before Self"*

**Nation First** is a minimalist, dignified single-page web application dedicated to the spirit of India. It serves as a digital portal honoring the Indian Armed Forces, the President, and national values through a clean, elegant interface inspired by the Tricolour.

## 🔗 Live Demo

**Experience the tribute here:** [https://my-desh-india.vercel.app/](https://my-desh-india.vercel.app/)

## ✨ Key Features

*   **Patriotic Design System:** A carefully curated color palette featuring India Saffron, India Green, and Navy Blue, complemented by a rotating Ashoka Chakra watermark.
*   **Official Directory:** Quick, card-based access to official portals for the Indian Army, Navy, Air Force, Coast Guard, and Supreme Command offices.
*   **Interactive Hero Section:** Features the National Flag with a smooth sheen effect and a rotating display of powerful national mottos.
*   **Responsive UI:** Fully responsive layout built with Tailwind CSS, ensuring a seamless experience across mobile, tablet, and desktop devices.
*   **Performance:** Built on Vite for lightning-fast loading and optimized asset delivery.

## 🛠️ Tech Stack

*   **Frontend Framework:** React 18
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **Build Tool:** Vite
*   **Icons/Assets:** Wikimedia Commons (SVGs)

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

*   Node.js (v18 or higher)
*   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/patriotic-tribute.git
    cd patriotic-tribute
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
